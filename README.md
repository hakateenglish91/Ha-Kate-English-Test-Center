# Ha Kate Test Center

Trang thẻ từ, bài kiểm tra và game tiếng Anh của CLB Tiếng Anh Cô Hà Kate (Hoàng Mai, Hà Nội).

- Trang học sinh: https://hakateenglish91.github.io/Ha-Kate-English-Test-Center/
- Dữ liệu (bài, thẻ từ, kết quả) nằm trong Google Sheet "Ha Kate English and Test Center" của cô; trang này chỉ hiển thị và gửi bài qua Google Apps Script.
